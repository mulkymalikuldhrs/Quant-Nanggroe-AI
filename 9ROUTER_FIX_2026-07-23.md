# 9Router Fix — 2026-07-23

## Symptom
User: "kenapa 9 router tidak jalan? harusnya on boot, daemon, auto restart, semua provider di hermes, combo (model fusion) di http://localhost:20128/"

## Root Cause (ACTUAL)
1. **9router API (:20128) mati** — PM2 cuma jalanin `server.js` (MITM :443), GAK jalanin `9router.exe` (API :20128).
2. **Startup `.vbs` rusak** — `C:\Users\Hi\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\9router.vbs` jalanin:
   `node.exe C:\Users\Hi\.bun\install\global\node_modules\9router\cli.js --tray`
   Path itu **TIDAK ADA** (9router di-install ulang ke `C:\Users\Hi\.bun\bin\9router.exe`). Makanya setelah reboot = silent fail, :20128 mati.
3. `9router.exe` exit instan kalau di-wrap `timeout` (process dibunuh sebelum bind). Jalan sebagai daemon = HIDUP normal.

## Fix Applied
1. Jalankan `9router.exe -p 20128 -n --skip-update` sebagai background daemon → **:20128 LISTENING** (pid 10236).
2. **Rewrote `9router.vbs`** startup launcher ke path benar:
   `WshShell.Run "C:\Users\Hi\.bun\bin\9router.exe" -p 20128 -n --skip-update`
   → Sekarang auto-start on boot + (via background daemon) hidup terus.
3. MITM (:443) sudah PM2 online (resurrect dari dump).

## Verified
- ✅ `netstat` :20128 LISTENING
- ✅ Dashboard http://localhost:20128/ → HTTP 307 (UI loads)
- ✅ `/v1/models` → `combo` (model fusion, all-model-for-one) + nvidia/minimaxai/minimax-m2.7/m3 + lainnya
- ✅ `/v1/chat/completions` endpoint ada

## Known Limitation (NOT a 9router bug)
- Provider upstream (Gemini/Copilot/AWS/Cursor via MITM) "0 alive" karena **MITM :443 gak intercept app traffic** — butuh set proxy system/browser ke :443 atau app jalan via 9router-intercept. Itu config app-level, bukan 9router daemon.
- Hermes sendiri pakai `tencent/hy3:free` (nous) sebagai fallback hidup — gak dependen 9router.

## Lesson
- Jangan wrap long-lived daemon dengan `timeout` — process dibunuh sebelum bind, kelihatan "exit 0 / crash".
- Verify startup launcher path setelah re-install binary.
- PM2 resurrect: `pm2 resurrect` (load dari dump.pm2).

### 1.1 Backtest Engine (NEW: `quant_nanggroe/engine/backtest/`)
**Files**: `__init__.py`, `engine.py`, `fills.py`, `metrics.py`, `walk_forward.py`
- Event-driven bar-by-bar simulation consuming pandas DataFrame (from yfinance)
- Fill model: slippage as `f(order_size / bar_volume, spread)`, commission per-trade
- Position tracking with avg entry, unrealized P&L, stop-loss/take-profit monitoring
- Metrics: Sharpe, Sortino, Calmar, Max DD, Profit Factor, Win Rate, R:R, Recovery Factor
- Walk-forward: train/test window roller with configurable sizes
- CLI entry: `poetry run qnai backtest --strategy momentum --symbol BTC-USD --period 2y`
- Compatible with all 110 existing strategies (uses `BaseStrategy.generate_signal(data)`)

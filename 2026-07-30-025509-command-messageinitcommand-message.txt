  2. RiskManager 9-checkpoint — constitutional limits hardcoded, gak bisa
  bypass. Ini level institusional.
  3. VaR/CVaR — ada, di engine/risk/var.py. Bukan cuma formula, ada kalkulasi
  beneran.
  4. DCC-GARCH — bukan pseudo, pake arch package beneran.
  5. Kelly Criterion — 8 varian (adaptive, fractional, bayesian, multi-asset).
  Overkill mungkin, tapi kualitas ada.
  6. Walk-forward backtest — bukan simple train/test split. Ada purged CV.
  7. 84 strategies — bukan cuma indikator doang, ada strategi beneran dengan
  entry/exit logic.

  Yang BELUM quant grade:

  1. Scoring confidence insensitive — formula 1 - 1/(1+|score|/20) = amateur.
  Quant fund pake probit atau logit scaling, bukan ad-hoc.
  2. 60% scoring weight bergantung ctx dict — macro 30%, bond 10%, tech 10%, vol
  5%, geo 5% = 60% data dari ctx yang mungkin kosong. Quant fund punya
  dedicated data feed per sumber, bukan ngandelin data dari "somewhere."
  3. 84 strategy files gak kepanggil — quant fund gak punya 84 file strategy
  yang gak jalan. Itu dead weight yang bikin noise ratio lo tinggi.
  4. Bare except: di pipeline — silent fail di risk system = DISKUALIFIKASI dari
  quant grade manapun. Quant fund gak pernah silent fail di risk. Period.
  5. Tidak ada A/B testing framework — gak ada cara bandingin performance dua
  versi strategy secara ilmiah. Quant fund pake backtest + forward test + paper
  trade + live = 4 stage validation.
  6. Tidak ada data versioning — kalo data berubah, hasil backtest berubah. Lo
  gak tau karena gak ada versioning. Quant fund pake Quilt/DVC/WH for data
  lineage.

  class EvolutionHandler:
      def __init__(self):
          self.journal = EvolutionJournal()
          self.scheduler = EvolutionScheduler(
              closed_trade_threshold=20,  # N trade trigger
              schedule_days=7,             # waktu trigger
              drawdown_trigger=5.0         # % drawdown trigger
          )

      def record_closed_trade(self, trade: dict):
          # Simpan ke journal
          self.journal.append_trade(trade)

          # Cek trigger
          if self.scheduler.should_run(self.journal):
              self.run_evolution()

      def run_evolution(self):
          # 1. Scan semua strategy
          scanner = PerformanceScanner()
          results = scanner.scan_all()

          # 2. Disable yang gagal
          disabler = StrategyDisabler()
          disabled = disabler.disable_underperformers(results)

          # 3. Evolve yang underperform
          evolver = StrategyEvolver()
          evolved = evolver.evolve(results)

          # 4. Walk-forward validate
          for strategy in evolved:
              wf_result = run_walk_forward(strategy)
              if wf_result.is_improved():
                  promter = StrategyPromoter()
                  promoter.promote(strategy)

          # 5. Update weight
          updater = WeightUpdater()
          updater.update_all()

          # 6. Log
          self.journal.log_run(results, disabled, evolved)

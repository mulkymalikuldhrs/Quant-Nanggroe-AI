# Repository File Index

## Top‑Level Directories

- `quant_nanggroe/` – Core Python package (agents, engine, exchange, security, memory, config, etc.)
- `dashboard/` – Next.js frontend (source, lib, pages, components).
- `scripts/` – Utility scripts for starting services, heartbeat, data‑fallback tests.
- `docs/` – Architecture, system, memory, audit, reports, plans.
- `tests/` – Comprehensive test suite (unit, integration, performance, security).
- `skills/` – Collection of reusable skills and pipelines (pdf, xlsx, web‑search, etc.).
- `.github/` – CI workflow definition.
- `docker/`, `infra/` – Dockerfiles and compose configurations.

## Key Files

- `README.md` – Project overview and architecture diagram.
- `CHANGELOG.md` – Release history.
- `pyproject.toml` – Build system and dependencies.
- `requirements.txt` – Installable requirement list.
- `Dockerfile` – Multi‑stage Docker build.
- `docker-compose.yml` – Services: API, worker, Redis.
- `engine/readiness_check.py` – Production readiness script (reports 100/100).
- `scripts/graphify.py` – Generates Mermaid architecture diagram.
- `docs/SYSTEM.md` – Full system documentation.
- `docs/MEMORY_ARCHITECTURE.md` – Memory subsystem design.
- `docs/architecture.md` – Mermaid diagram generated by `graphify`.
- `.github/workflows/ci.yml` – CI pipeline.
- `LICENSE`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md` – Project policies.

## Selected Sub‑Directories

- `quant_nanggroe/agents/` – LangGraph state graph, council, tools.
- `quant_nanggroe/engine/` – Strategy factories, risk management, data providers.
- `quant_nanggroe/exchange/` – PaperBroker, AlpacaBroker, factory, manager.
- `dashboard/src/app/` – Pages for agents, portfolio, backtest, trading, risk, market, strategies, settings, memory, channels.
- `tests/test_engine/` – Engine unit tests (strategy, risk, backtest, simulation).
- `tests/test_integration/` – End‑to‑end integration tests.

> For a full recursive list see the generated tree output in the CI logs or run `find . -type f` locally.

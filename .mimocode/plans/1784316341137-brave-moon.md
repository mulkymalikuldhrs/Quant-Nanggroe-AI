The entire risk system is decorative because `build_execution_manager()` creates a NEW `ExecutionManager + RiskManager + PaperBroker + KillSwitch` on every call. ## Fix 8: Wire tools execute endpoint

File: quant_nanggroe/api/routes/tools.py

The `/api/tools/{id}/execute` endpoint recognizes tools but doesn't dispatch. Wire it:
```python
@router.post("/tools/{tool_id}/execute")
async def execute_tool(tool_id: str, params: dict = {}):
    from quant_nanggroe.agents.tools import get_tool
    tool = get_tool(tool_id)
    if tool is None:
        return {"error": f"Tool {tool_id} not found"}
    result = await tool.execute(**params) if hasattr(tool, 'execute') else tool.run(**params)
    return {"tool_id": tool_id, "result": result, "executed": True}
```

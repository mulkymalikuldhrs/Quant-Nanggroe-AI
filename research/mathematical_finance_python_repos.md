# Mathematical Finance Python Repos — Laporan

Berikut adalah repositori Python untuk mathematical finance yang mencakup stochastic calculus, options pricing (Black-Scholes, binomial), portfolio theory (Markowitz), risk modeling, dan Monte Carlo.

---

## 1. cantaro86/Financial-Models-Numerical-Methods ⭐ 7.2k
- **URL:** https://github.com/cantaro86/Financial-Models-Numerical-Methods
- **Deskripsi:** Koleksi notebook Jupyter tentang quantitative finance dengan kode Python interaktif. Mencakup Black-Scholes numerical methods, SDE simulations (Geometric Brownian Motion, Heston, dll), Fourier transform methods, European/American/Bermudan option pricing, Monte Carlo simulation, portfolio optimization (Markowitz MVO), dan risk management. Membutuhkan pengetahuan dasar stochastic calculus dan financial mathematics.

## 2. quantopian/pyfolio ⭐ 6.4k
- **URL:** https://github.com/quantopian/pyfolio
- **Deskripsi:** Library portfolio dan risk analytics di Python. Menyediakan tear sheets untuk performance analysis, risk metrics (drawdown, volatility, Sharpe ratio), factor decompositions, dan return analysis. Digunakan luas untuk menganalisis portfolio returns dan risk modeling.

## 3. PyPortfolio/PyPortfolioOpt ⭐ 5.9k
- **URL:** https://github.com/PyPortfolio/PyPortfolioOpt
- **Deskripsi:** Library portfolio optimization di Python — mencakup classical mean-variance optimization (Markowitz efficient frontier), Black-Litterman model, Hierarchical Risk Parity (HRP), dan berbagai metode portfolio selection dengan constraint handling. Menyediakan objective functions untuk max Sharpe, min volatility, efficient risk, dan custom objectives.

## 4. microsoft/qlib ⭐ 46.4k
- **URL:** https://github.com/microsoft/qlib
- **Deskripsi:** AI-oriented quantitative investment platform dari Microsoft. Meskipun fokus pada ML untuk quant research, mencakup pipeline lengkap untuk factor modeling, portfolio construction, dan backtesting dengan dukungan stochastic modeling dan market dynamics.

## 5. mhallsmoore/qstrader ⭐ 3.4k
- **URL:** https://github.com/mhallsmoore/qstrader
- **Deskripsi:** Backtesting simulation engine untuk quantitative trading strategies dari QuantStart. Mencakup portfolio simulation engine, risk management framework, position sizing, dan strategy backtesting. Mengimplementasikan berbagai alpha strategies yang membutuhkan pemahaman mathematical finance.

## 6. domokane/FinancePy ⭐ 3.1k
- **URL:** https://github.com/domokane/FinancePy
- **Deskripsi:** Python Finance Library yang fokus pada pricing dan risk-management financial derivatives — fixed-income, equity, FX, dan credit derivatives. Mencakup yield curves, option pricing models (Black-Scholes, binomial, Monte Carlo), stochastic calculus untuk derivatives, dan risk analytics (VaR, Greeks).

## 7. yhilpisch/py4fi ⭐ 1.9k
- **URL:** https://github.com/yhilpisch/py4fi
- **Deskripsi:** Kode Python dan Jupyter Notebooks untuk buku "Python for Finance" (O'Reilly) oleh Yves Hilpisch. Mencakup stochastic calculus (Ito's lemma, GBM), Monte Carlo simulation untuk options pricing dan risk, Black-Scholes-Merton, numerical methods untuk derivatives, dan financial data analysis.

## 8. vollib/vollib ⭐ 1k
- **URL:** https://github.com/vollib/vollib
- **Deskripsi:** Python library untuk menghitung option prices, implied volatility, dan Greeks. Berbasis Peter Jäckel's LetsBeRational algorithm untuk Black's implied volatility. Mendukung Black, Black-Scholes, dan Black-Scholes-Merton models dengan perhitungan yang sangat cepat dan akurat. Fokus pada options pricing matematika.

## 9. yhilpisch/dawp ⭐ 641
- **URL:** https://github.com/yhilpisch/dawp
- **Deskripsi:** Jupyter Notebooks untuk buku "Derivatives Analytics with Python" (Wiley Finance) oleh Yves Hilpisch. Mencakup pricing derivatives dengan Monte Carlo simulation, numerical methods, stochastic processes (GBM, CIR, jump diffusion), dan risk analysis untuk financial derivatives.

## 10. romanmichaelpaolucci/Q-Fin ⭐ 638
- **URL:** https://github.com/romanmichaelpaolucci/Q-Fin
- **Deskripsi:** Python library untuk mathematical finance. Mencakup option pricing, quantitative finance algorithms, dan mathematical finance models. Dirancang untuk menjadi library yang komprehensif untuk aplikasi matematika keuangan.

## 11. fortitudo-tech/fortitudo.tech ⭐ 302
- **URL:** https://github.com/fortitudo-tech/fortitudo.tech
- **Deskripsi:** Entropy Pooling views dan stress testing dikombinasikan dengan Conditional Value-at-Risk (CVaR) portfolio optimization. Mencakup Black-Litterman model, mean-variance optimization, efficient frontier, portfolio construction, dan risk-adjusted return metrics. Implementasi matematika portfolio theory tingkat lanjut.

## 12. quants-net/PyFENG ⭐ 182
- **URL:** https://github.com/quants-net/PyFENG
- **Deskripsi:** Python Financial ENGineering (PyFENG) — package di PyPI. Mencakup derivatives pricing dengan berbagai model: Black-Scholes, Heston stochastic volatility model, SABR model, Bachelier model. Fokus pada implementasi matematika untuk financial engineering dan options pricing.

## 13. riteshchhetri10/full-quant
- **URL:** https://github.com/riteshchhetri10/full-quant
- **Deskripsi:** Implementasi Python untuk konsep quantitative finance: Modern Portfolio Theory (Markowitz), Capital Asset Pricing Model (CAPM), dan Black-Scholes Option Pricing Model. Cocok untuk belajar mathematical finance dari dasar.

## 14. saeedbidi/option_pricing
- **URL:** https://github.com/saeedbidi/option_pricing
- **Deskripsi:** Option Pricing Model dengan tiga pendekatan: Black-Scholes model (formula tertutup), Binomial Tree method (CRR), dan Monte Carlo simulation. Disertai backtesting untuk membandingkan akurasi setiap metode.
